「내 방식 QR」 시스템 구조도

2026 AI 라이프 솔루션 챌린지 · 아이디어 5번 · 2026.10.20 · 시제품 기준

1. 시스템 구성도

키오스크 (매장)

React 웹 · /kiosk
  • 주문 창구 열기
  • QR 표시 (매장 + 창구번호)
  • 주문번호 표시

사용자 휴대폰

React 웹 · /m · 앱 설치 없음
  • 접근성 설정 선택·폰에만 저장
  • 맞춤 화면 그리기 (화면 부품)
  • 메뉴·옵션 선택, 주문

우리 서버

FastAPI (Python)
  • 메뉴 원본 보관 (가격의 유일한 출처)
  • 변환 결과 저장본 관리
  • AI 결과 검사 6가지
  • 가격 재계산 · 목업 결제 · 주문번호

AI

Claude API (형식 강제 출력)
  • 쉬운 설명·질문 문구
  • 메뉴 묶음·순서
  • 옵션 묻는 순서
  • 가격은 받지도 정하지도 않음
원칙: 키오스크는 QR만 띄우고, 폰은 화면만 그리고, AI는 설계도만 만들고, 판단(검사·가격·주문)은 전부 서버가 한다. AI와 통신하는 것은 서버뿐이다 (API 키는 서버에만 보관).

2. 시퀀스 다이어그램 (시간 순서)

실선 = 네트워크 요청 · 점선 = 응답 / 통신 아님 · 회색 상자 = 내부 처리. 저장본이 있으면 ⑨~⑪(AI 호출)을 건너뛴다.
