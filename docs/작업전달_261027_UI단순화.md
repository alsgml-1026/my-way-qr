## 3. [Part A] UI/UX 단순화 상세 내역

### ① `/m/setup` (`SetupPage.tsx`) — 은행 ATM기 방식 2단계 카드형 위저드
- **한 화면에 질문 1개씩만** 큼직한 카드 버튼(높이 72px, 22px 굵은 글씨)으로 물어봅니다.
  - **1단계 (`step = 1`)**: *"주문할 때 어떤 도움이 필요하신가요?"*
    - `👵 큰 글씨 · 쉬운 말로 보기` (`senior`)
    - `⚡ 자주 시키는 메뉴 바로 고르기` (`quick`)
    - `👍 기본 화면으로 보기` (`standard`)
  - **2단계 (`step = 2`)**: *"건강상 피해야 할 성분이 있으신가요?"*
    - `🍬 당류 줄이기 (당뇨·혈당 관리)` (`low_sugar`)
    - `☕ 카페인 피하기 (혈압·불면 관리)` (`decaf`)
    - `🥗 칼로리 줄이기 (식단·체중 관리)` (`low_calorie`)
    - `✅ 특별히 피할 성분 없음`

### ② `/m` (`PhoneOrderPage.tsx`) — 카테고리 탭 + 1줄 통합 신호등 배지
- **카테고리 탭 분리**: `⭐ 추천/전체`, `☕ 커피`, `🍵 차·논커피`, `🥐 디저트` 탭으로 한 화면 메뉴 수를 최소화했습니다.
- **1줄 통합 신호등 배지 (`getSignalBadge`)**:
  - 주의 메뉴: **빨간 배지 1줄** (`⚠️ 당 많음 30g · 카페인 150mg · 250kcal`)
  - 안심 메뉴: **초록 배지 1줄** (`● 안심 (주의 성분 없음) · 0kcal`)

## 4. [Part B] AI 기술 점수 극대화용 3대 킬러 기능 (내일 이어서 점검할 항목)

### 기능 1. 🎤 점원에게 말하듯 한마디 주문 (Voice / Intent-to-Order AI)
- **위치**: 모바일 주문 화면(`/m`, `PhoneOrderPage.tsx`) 상단 주황색 카드
- **핵심 동작**:
  - 어르신이 메뉴 이름(예: 캐모마일, 아메리카노)을 몰라도 **"나 당뇨가 있어서 단 건 안 되고 밤에 잠 잘 오는 따뜻한 차 줘"**처럼 말하거나 텍스트/예시 버튼을 누르면 작동합니다.
  - **STT 구조 (서버 메모리 부담 0MB)**:
    1. **1순위**: 브라우저 내장 `Web Speech API` (`webkitSpeechRecognition`, `ko-KR`)로 즉시 무료 음성 인식
    2. **2순위 (Fallback)**: `MediaRecorder`로 음성 녹음 후 백엔드 `POST /api/stt` 전송 → OpenAI `whisper-1` API로 텍스트 변환
    3. **3순위 (시연 안전장치)**: 마이크가 없는 PC 시연 환경을 위해 원터치 예시 발화 버튼 3종 제공
  - **AI 의도 분석 (`POST /api/intent-order`)**:
    - 사용자 발화 + 현재 건강 프로필(`avoid_tags`) + 매장 전체 메뉴/옵션/영양성분을 `gpt-4o-mini` Structured Outputs로 분석하여 **가장 안전한 메뉴 1개와 세부 옵션(따뜻하게/차갑게, 크기 등)까지 한 번에 자동 선택**합니다.
    - **`✅ 이대로 장바구니에 바로 담기`** 버튼 1번만 누르면 옵션 화면을 거치지 않고도 장바구니에 즉시 담깁니다.
    - *(가격/영양성분 무결성 보장)* LLM이 가격을 지어내지 못하도록, 서버(`ai_assist.py`)가 실제 매장 JSON에서 정확한 단가와 옵션 합산 금액을 계산해 반환합니다.

### 기능 2. 🔄 위험 메뉴 선택 시 AI 건강 대체 메뉴 역제안 (Smart Swap AI)
- **위치**: 메뉴 옵션 선택 화면(`/m/item/:itemId`, `ItemOptionsPage.tsx`) 상단
- **핵심 동작**:
  - 당류·카페인 주의 설정을 한 어르신이 위험 메뉴(예: `바닐라라떼`, 당 30g / 카페인 150mg)를 눌렀을 때, 단순히 경고만 띄우는 것이 아니라 `POST /api/smart-swap`을 호출합니다.
  - **2가지 원터치 처방 제시**:
    1. **현재 메뉴 내 안전 옵션 자동 변경**: 해당 메뉴에 `디카페인 변경` 옵션이 있으면 **`✨ 원터치 적용: 디카페인으로 옵션 자동 변경`** 버튼 노출 → 누르면 즉시 디카페인 라디오 버튼이 선택됨.
    2. **매장 내 안전한 대체 메뉴 추천**: 같은 매장에서 맛/분위기가 비슷하면서 위험 성분이 없는 대체 메뉴(예: `캐모마일 차 (당 0g · 카페인 0mg)`) 카드를 띄우고, **`👉 이 안전한 메뉴로 바로 바꾸기`** 버튼을 누르면 해당 메뉴로 즉시 이동.
  - **동료분의 2번째 매장(분식집) 호환성**: 매장 JSON의 `health`(당류/카페인/칼로리/나트륨/알레르기) 데이터를 동적으로 읽어 작동하므로 카페뿐만 아니라 분식집 매장에서도 그대로 작동합니다.

### 기능 3. 📸 사장님용: 종이 메뉴판 사진 1장 → Vision AI 10초 매장 자동 생성기
- **위치**: 실험실 화면(`/lab`, `LabPage.tsx`) 최상단
- **핵심 동작**:
  - 동네 카페/분식집 사장님이 스마트폰으로 찍은 **종이 메뉴판 이미지 1장**을 업로드(`POST /api/vision-store`)하면, OpenAI Vision(`gpt-4o-mini`)이 메뉴명·가격·카테고리를 추출하고 **어르신용 쉬운 설명(`easy_desc`) + 예상 영양성분(`health`) + 기본 옵션**까지 자동으로 채운 매장 JSON을 생성합니다.
  - 이미지 없이도 시연할 수 있도록 버튼 클릭 시 기본 샘플(동네 옛날 다방·분식 메뉴판) 자동 생성 Fallback도 포함되어 있습니다.
