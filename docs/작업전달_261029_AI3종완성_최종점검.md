## 1. 한 줄 요약 (무엇을 왜 바꿨나)

2026 AI 라이프 솔루션 챌린지 심사(대국민 투표 + 전문가 심사)에서 **① 고령층 실제 사용성**과 **② AI 기술 활용 독창성** 점수를 극대화하기 위해 다음 4가지를 완성했습니다.

1. **[핵심 기능] 🎤 할머니·할아버지 말 한마디 → 메뉴·옵션·수량 자동 변환 & 원터치 즉시 주문 (`/m`)**
   - 메뉴 이름(캐모마일, 아메리카노, 로제떡볶이 등)이나 옵션 영어를 전혀 몰라도 **"나 당뇨가 있어서 단 건 안 되고 밤에 잠 잘 오는 따뜻한 차 줘"** 또는 **"가슴 안 두근거리는 디카페인 커피 시원하게 두 잔 줘"**처럼 말하면, AI 점원이 건강 설정(`watch`, `allergies`)과 대조해 **가장 안전한 메뉴 + 세부 옵션 + 수량까지 한 번에 변환**합니다.
   - 변환 결과를 **한국어 음성(TTS)**으로 읽어 주며, **`⚡ 네, 이 메뉴로 바로 주문(결제 완료)하기 →`** 버튼 **단 한 번**만 누르면 옵션/장바구니 화면을 거치지 않고도 **즉시 주문번호가 발급(키오스크 화면에도 동시 표시)**됩니다.
2. **🔄 위험 메뉴 선택 시 AI 건강 지킴이 대체 제안 — Smart Swap (`/m/item/:id`)**
   - 당류·카페인·나트륨·알레르기 주의 설정을 한 어르신이 위험 메뉴(예: `바닐라라떼`, `떡볶이`)를 눌렀을 때, 경고만 띄우는 데 그치지 않고 **① 원터치 안심 옵션 변경(`디카페인 원두로 변경`, `순한맛으로 미리 선택`)** 및 **② 매장 내 안전한 대체 메뉴(`캐모마일`, `김밥` 등)로 즉시 바꾸기**를 제안합니다.
   - 원터치 옵션 변경 클릭 시 이미 선택된 옵션 질문 단계는 자동으로 건너뛰어 어르신이 같은 질문을 두 번 답하지 않게 개선했습니다.
3. **📸 사장님용: 종이 메뉴판 사진 1장 → Vision AI 10초 매장 자동 생성기 (`/lab`)**
   - 소상공인 사장님이 JSON 파일을 직접 작성할 필요 없이, 스마트폰으로 찍은 **종이 메뉴판 사진 1장**을 올리면 OpenAI Vision(`gpt-4o-mini`)이 **메뉴·가격·쉬운 설명·꼭 남길 정보(`must`)·예상 영양성분·알레르기 태그**를 자동 추출해 즉시 QR 매장으로 개설합니다.
4. **🏦 은행 ATM식 2단계 설정 위저드 (`/m/setup`) + 2번째 매장(`모두의 분식`) 영양·AI 연동**
   - 복잡한 다중 칩 설정 화면을 **한 화면에 큰 카드 질문 1개씩 묻는 ATM 2단계 위저드**로 단순화했습니다.
   - `모두의 분식`(`modui-bunsik.json`) 11개 메뉴에 영양성분(`kcal`, `sugar`, `sodium`, `caffeine`)과 알레르기 정보를 추가하여, 분식집에서도 **나트륨/새우 알레르기 경고 배지·음성 주문·Smart Swap**이 모두 작동합니다.

## 3. 서비스 핵심 원칙(`AGENTS.md`) 준수 확인

1. **가격·금액 무결성 100% 보장**:
   - 새로 추가된 음성 주문(`/api/intent-order`)과 대체 추천(`/api/smart-swap`)에서도 **AI는 메뉴 ID와 옵션 ID만 고르며, 단가와 합계 금액은 무조건 서버가 매장 원본 JSON에서 계산**합니다.
   - 실제 결제(`POST /api/orders`) 역시 기존과 동일하게 서버 `price_line()`이 재계산합니다.
2. **건강 정보 프라이버시 및 안전성**:
   - 기본 메뉴판 변환(`/api/transform`) 시에는 건강 설정이나 영양 수치를 AI로 보내지 않으며, 음성 맞춤 추천 시에만 휘발성으로 매칭하고 **서버 DB나 사용자 테스트 로그(`사용자테스트.csv`)에는 건강 정보를 일절 기록하지 않습니다.**
   - 의학적 진단 문구 대신 성분 사실(`당 많음 30g`, `카페인 있음 150mg`, `나트륨 많음 1,250mg`)만 표시합니다.
3. **100% 무중단 시연 보장 (Dual Fallback)**:
   - 음성 인식: `브라우저 Web Speech API (무료·실시간)` → 실패 시 `MediaRecorder + OpenAI Whisper API (/api/stt)` → 마이크 없는 PC 환경에서는 `원터치 어르신 말씀 예시 버튼 3종`으로 시연 가능.
   - 의도 분석 및 매장 생성: `OpenAI API 키`가 없거나 네트워크가 끊겨도 내장된 규칙 기반 엔진(`rule-fallback`)이 즉시 동작해 시연이 절대 멈추지 않습니다.

## 4. 동료분 참고용: 보고서·발표자료·시연 영상 핵심 어필 포인트

### ① 시연할 때 가장 임팩트 있는 30초 시나리오
1. **설정 (`/m/setup`)**: ATM처럼 큰 카드에서 **`왕큰 글씨 + 쉬운 말`** 클릭 → 2단계에서 **`당류 조심` + `카페인 조심`** 클릭
2. **음성 원터치 주문 (`/m?store=modui-cafe`)**:
   - 상단 마이크 박스에서 *"가슴 안 두근거리는 디카페인 커피 시원하게 두 잔 줘"* 말하기(또는 예시 버튼 클릭)
   - AI 점원이 **`아메리카노 × 2개 (ICE · R · 기본 · 디카페인) · 8,000원`**으로 자동 변환하고 한국어 음성(TTS)으로 안내
   - **`⚡ 네, 이 메뉴로 바로 주문(결제 완료)하기 →`** 버튼 1번 클릭 → 즉시 주문 완료 화면(`/m/done`)과 키오스크(`/kiosk`)에 같은 주문번호 표시!
3. **Smart Swap 시연 (`/m/item/vanilla-latte`)**:
   - 메뉴판에서 빨간 배지(`⚠️ 당 많음 30g · 카페인 있음 150mg`)가 붙은 **`바닐라라떼`** 클릭
   - 상단 **🔄 AI 건강 지킴이 대체 제안**에서 **`✨ 원터치 적용: 카페인 뺀 『바닐라라떼 (디카페인)』으로 옵션 변경`** 또는 **`걱정 없는 안심 메뉴 『캐모마일』로 바꾸기`** 클릭
4. **분식집 확장 & 사장님용 Vision AI 시연 (`/m?store=modui-bunsik`, `/lab`)**:
   - 분식집에서 *"매운 거 못 먹는데 안 맵고 부드러운 떡볶이 줘"* → **`로제떡볶이 (순한맛 · 기본)`** 자동 변환 확인
   - `/lab` 상단에서 메뉴판 사진 업로드(또는 버튼 클릭) → 10초 만에 새 매장(`정겨운 우리동네 국수·분식`) 생성 및 주문판 열기 확인
